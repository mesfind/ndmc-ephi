Course Learning Objectives

By the end of this workshop, participants will be able to:

  • Automate data processing tasks using shell scripting
  • Use Git and GitHub for version control and collaboration
  • Create reproducible research documents with Quarto
  • Integrate shell scripts, version control, and documentation in a complete workflow
  • Publish reproducible analyses that others can easily verify and build upon

Prerequisites

Basic computer literacy. No prior experience with command line, Git, or Quarto required.
