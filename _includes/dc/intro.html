This Shell Scripting, GitHub, and Quarto for Reproducible Research workshop equips researchers with essential computational skills to enhance productivity, ensure reproducibility, and facilitate collaboration in scientific work. Through hands-on sessions, participants will learn to automate workflows, implement version control, and create dynamic, publication-ready documents that integrate code, data, and narrative in a single reproducible framework.

The workshop covers three core pillars of modern computational research:

  • Shell Scripting: Automate data processing, file management, and workflow automation
  • Git & GitHub: Implement version control, collaborate effectively, and manage project history
  • Quarto: Create reproducible documents that combine analysis code, results, and narrative text

Participants will work on practical examples and apply these tools to their own research contexts, building a complete reproducible workflow from data processing through to publication-ready outputs. The workshop emphasizes hands-on learning, peer support, and direct application to real research challenges.

This workshop follows established best practices for scientific computing. For more information on our teaching philosophy, please see: " Best Practices for Scientific Computing" and " The Turing Way: A guide for reproducible data science".

Who Should Attend?

This workshop is designed for researchers, graduate students, and professionals who want to improve their computational workflow efficiency and research reproducibility. No prior experience with command line, version control, or Quarto is required.
